# Climb — animated climbing-wall process

[Open the interactive animation](https://yahito.github.io/climbplywood/) · [Watch the 42-second MP4](https://yahito.github.io/climbplywood/climbing-wall-process.mp4)

An interactive Three.js process study showing CNC machining of plywood panels, rear T-nut installation, and climbing-wall assembly. Includes playback, chapter selection, timeline scrubbing, speed controls, camera orbit, and zoom. Supports mobile screens and reduced-motion preferences.

[Components and EUR cost planner](https://yahito.github.io/climbplywood/#budget) includes editable prices and quantities, whole-sheet and whole-pack purchasing, transport allowances, contingency, and supplier references. Compare retail with EU value sourcing, and compare a wholesale or non-EU import quote after freight, quoted duties, VAT and clearance fees. Estimates are saved in the browser.

Open `animation/index.html` locally; no build or installation is required. See [animation/README.md](animation/README.md) for controls, development checks, and video export instructions.

GitHub Actions publishes the animation and MP4 to GitHub Pages on every push to `main`. The deployment packages runtime assets from `animation/` and the video from `output/animation/`.

Concept illustration only. Frame and building anchors require site-specific design.
